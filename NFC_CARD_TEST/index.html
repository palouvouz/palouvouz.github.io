σε τι δούλεψε (π.χ.: Hardware)

Εδω καθε μέλος μπορεί να περιγράψει με λιγα λογια τον/την εαυτο του/της την εργασία που έχει κάνει, τις δεξιότητες που έχει αναπτύξει και οποιαδήποτε άλλη πληροφορία θέλει να μοιραστεί. Σιγουρα θα πρεπει να εχει απαντισει (σε λιγοτερο απο 100 λεξεις):

  1. Για ποιο λόγο έκανες αίτηση;
  2. Τι σου άρεσε περισσότερο στην εμπειρία αυτή;
  3. Τι αποκόμισες από την εμπειρία αυτή;
  4. Αν το έκανες ξανά, τι θα έκανες διαφορετικά;
