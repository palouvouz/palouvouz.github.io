Morse Signal

I built Morse Signal as a native Android app that turns ordinary text into International Morse Code and transmits it through light, vibration and sound.

This is one of my vibe-coded projects, created with the help of Anthropic while I designed, tested and refined the application.

View on GitHub Explore the app

What I built

Morse Signal takes text, converts it into International Morse Code and sends the resulting signal using one or more physical outputs.

Flashlight

The phone's flashlight can transmit Morse visually using precisely timed flashes.

Vibration

Morse can also be transmitted through the device's vibration motor.

Audio

The app can generate an audible Morse signal with configurable frequency and volume.

One signal. Multiple outputs.

One of the main ideas behind Morse Signal is synchronization. Instead of creating separate timing systems for the flashlight, vibration and audio, I use a shared transmission engine.

This means that when several outputs are enabled, they follow the same Morse timing.

Example

A Morse dot lasts one timing unit, a dash lasts three, and the gaps between symbols, letters and words follow the standard International Morse timing.

Features I added

Live Preview

I can see the generated Morse code before transmitting it.

Voice Input

I can speak a message and let Android convert my speech into text before I transmit it.

SOS

A dedicated SOS action makes it possible to quickly transmit the standard Morse distress signal.

Quick Settings

I added a Quick Settings Tile for fast access to Morse SOS.

Home Screen Widget

The application also provides a widget with quick access to SOS and the main app.

Greek Support

Greek characters are not silently changed. If enabled, the app can optionally transliterate them into Latin characters before transmission.

Safety was important

I designed the transmission system so that pressing STOP immediately disables all active outputs.

The application also stops an active transmission when it leaves the foreground. This prevents the flashlight, vibration or audio from continuing unexpectedly.

STOP means STOP.

Even when an error, cancellation or interruption occurs, the outputs are explicitly shut down.

How I built it

Morse Signal is a native Android application written in Kotlin. I separated the Morse logic and transmission engine from the Android hardware layer so that the core logic remains easier to test and maintain.

Language

Kotlin 2.0

UI

Architecture

Flashlight

Local-first by design

I wanted the application to stay simple and private. Morse Signal does not require an account, backend server or analytics system.

The application's core functionality works locally on the Android device.
